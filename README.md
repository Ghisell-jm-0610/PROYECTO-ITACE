ITACE DIGITAL 4.0

Descripción

Proyecto académico enfocado en la modernización del sitio web del Instituto Tamaulipeco de Capacitación para el Empleo (ITACE), plantel Reynosa.

Objetivo

Mejorar la presentación y organización de la información del sitio web para facilitar el acceso a sus contenidos.

Tecnologías utilizadas

* HTML
* CSS
* JavaScript

Contenido del proyecto

* Página principal del ITACE.
* Imágenes relacionadas con las instalaciones y especialidades.
* Hoja de estilos para el diseño visual del sitio.
